# Contributing\n\n## Required deployment convention: keep the SPA shell uncached\n\nThe browser entry document must never be served as a publicly cached static fallback. Every browser route that is not an API route or a hashed asset must be routed through the application SPA shell handler at /api/spa.ts, which serves dist/public/index.html with Cache-Control: no-store, no-cache, must-revalidate, max-age=0.\n\nKeep Vite-generated files under /assets/ content-hashed and immutable:\n\n- Do not change the SPA rewrite to serve /index.html directly.\n- Do not give index.html or browser routes public/immutable caching.\n- If the build output or route structure changes, update vercel.json and verify a fresh deployment loads both the JS and CSS assets without a manual refresh.\n\nThis prevents a cached HTML shell from referencing JS or CSS hashes that belong to an older deployment.\n
